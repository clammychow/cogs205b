## Description
Implements a "Bayes Factor" class and test suite that allows you to compute the likelihood, spike evidence, slab evidence, and Bayes factor with some given n, k, and theta inputs.

## Files
- bayes_factor.py
- tests/test_bayes_factor.py

## Instructions
### Run in terminal to build image:
docker build -t bayes-factor .

### Run tests:
docker run --rm bayes_factor
