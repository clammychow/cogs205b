## Description
Implements a "Bayes Factor" class and test suite that computes the likelihood, spike evidence, slab evidence, and Bayes factor for some given n, k, and theta inputs.

## Files
- bayes_factor.py
- tests/test_bayes_factor.py

## Instructions
### Build Docker image:
docker build -t bayes-factor .

### Run tests:
docker run --rm bayes-factor
