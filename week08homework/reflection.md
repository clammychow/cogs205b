These differences might be because of the simplifications or because I created my class/test suite using scipy.stats.binom.pmf for likelihood while the model uses math.comb.

The model excessively comments the reasoning behind every line, sometimes leaves in scratch/unused code, and tries to handle some problems silently instead of raising errors. However, it also uses good practices like creating variables with informative names to avoid hard-coding or calling a method multiple times.
